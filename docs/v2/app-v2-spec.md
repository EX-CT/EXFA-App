# EXFA-App v2 — UI spec (lead-authored; implement exactly, ask only via report if something is impossible)

Target: landscape desktop, baseline 1920×1080, must stay fully usable at 1600×900. No page scroll: header + 3 columns fill 100vh, each panel scrolls internally. NOTHING opens as a page or full-screen list; no native alert/confirm/prompt anywhere (grep must return 0 in src/ excluding tests).

## Stage B — compact market, operation modes, compare strip
1. Market rows (Market.tsx): row height 18px; indent 8px per depth; caret 10px; group row = caret + name + muted item count. Type row = TypeIcon 16 (request size 32) | name (flex, ellipsis, title = full name + group) | meta badge right-aligned fixed 24px: text by meta group (T1 none, "T2", "F" faction, "D" deadspace, "O" officer, "S" storyline, otherwise "M{lvl}") coloured T2 gold, faction #5fbf77, deadspace #7aa7d9, officer #b38cff, storyline #c9a26b | slot letter (H/M/L/R/S, coloured) only in search results / "All" filter. The "i" button only appears on hover. No separate "kind" column.
2. Selection: App state `sel: {list:'modules'|'drones'|'fighters'|'cargo', index:number} | null`. Single click on a fitted row selects it (gold left border 2px + --sel background) AND keeps today's behaviour (locate in market + info pane). Click again or Esc deselects. Selection follows the item after replace.
3. Mode: header segmented control [智能 Smart (Q) | 替换 Replace (W) | 添加 Add (E)], keys inactive while typing; persisted in settings. Default Smart.
4. Market click semantics (user decision): single click = PREVIEW (sets `candidate` type id; compare strip switches to its tab and pins the candidate row on top); double click or Enter (row focused / candidate set) = APPLY. Drag-and-drop unchanged. Implement `applyMarketPick(ds, fit, sel, typeId, mode) → {fit, sel, note}` in fit/model.ts (pure, unit-tested):
   - ship → new fit (as today).
   - module/subsystem: Smart → replace when sel is a module and ds.slot(new) === sel slot, else add. Replace → requires sel module with same slot; otherwise no change + note warn "先选中一个同槽位的装备" / "槽位不同，无法替换". Add → add. Replace = whole link group (all modules sharing `group`); keep compatible charge; state = offline stays offline, else defaultState.
   - charge: sel module accepting it → load into sel module and its link group; else (no sel / Add) today's behaviour.
   - drone with sel drone → replace type keeping quantity/active; fighter with sel fighter → replace type, quantity = min(old, new squadron max); otherwise add.
   - implants/boosters: as today (replace same slot).
   - The note becomes a toast: "已替换 ×3 A → B · Ctrl+Z 撤销" (with undo action) / "已添加 B".
5. Compare strip (dock tab 对比), context = selected item (+ candidate):
   - Rows: baseline (current, muted, no deltas) ; candidate (if any, pinned, gold outline) ; then sub-tab content: [变种 Variations (ds.variations of the selected module, sorted by meta level) | 弹药 Charges | 离线贡献 Offline | 角色 Characters] — reuse fit/whatif.ts scenario builders. Drones/fighters selected → variations of that drone/fighter type. Nothing selected → hint text + the candidate as "add" preview.
   - Each row is a real engine calc of the edited fit (Promise.all on the worker, ≤60 rows, debounce 150 ms, cache by request JSON).
   - Columns: icon + name | CPU free after (Δ) | PG free after (Δ) | Cap Δ GJ/s (Δ) | up to 4 category metrics | price | [应用] button (applies like double-click; Smart/Replace semantics on the selected item regardless of mode).
   - Category metrics (pick by the SELECTED module's group/effects; candidate of a different category → CPU/PG/Cap then union of both sets, max 6): propulsion (AB/MWD/MJD): speed, align, sig, cap_delta · turret/launcher: dps, scenario dps (first active scenario, stage C; omit before), optimal+falloff or missile range, tracking · tank (shield/armor/hull HP, resist, repair, DC): ehp, tank (active HP/s), speed, sig · ewar/tackle (web, scram, point, damp, ECM, TD, painter, neut/nos): cap_delta, the module's own range, speed · capacitor modules: cap_delta, cap stability/time · otherwise: dps, ehp, tank, cap_delta, speed, align. Extend fit/metrics.ts with any missing metric (each metric declares higherIsGood). Users can pin metrics: click a column header pin icon; pinned set persisted per category in settings, shown first.
   - Cell format "38.0 (+8.0)": delta coloured --ok when better, --bad-ish text (#e0736f) when worse, --dim when 0.
   - Row frame: red 1px outline + red left bar when the variant introduces violations absent from the baseline (tooltip lists them, localised); amber outline when it introduces new missing-skill warnings. A candidate that can't be fitted at all → row shows the reason.
6. Module row: tiny "⇄n" button when variations exist → selects the row and opens Compare/变种. Center tab "What-if" and the 5th dock tab are removed (all in the strip).

## Stage D — library on @exfa/format
1. Depend on `@exfa/format` via `github:EX-CT/EXFA-Format#v1.0.0`. The app's internal model becomes FitDocument / Library@1 (replace fit/model.ts Fit/Library types; `toRequest` → format `resolve`; keep helper functions like addItemToFit/moveModule operating on `doc.fit`). Engine requests = `resolve(lib, id)` (+ price options as today).
2. Storage: keep IndexedDB db name "eve-fit-web" (user data must survive), bump version to 2, new object store "docs" (FitDocument by id) + kv "index" (library-index content); on first open migrate from store "fits"/kv via format `migrate`, leave old stores untouched as backup. localStorage fallback same idea. History: every save goes through `recordHistory`.
3. Library panel (FitBrowser): folder tree (any depth, drag fits onto folders, InlineEdit rename on F2/double-click, inline new folder, context menu). Fleets shown as nodes with members + role badge (指挥/成员); fit context menu: "加入编队 ▸ <fleet>/新编队", "设为指挥/设为成员", "移出编队". Fit node expandable: branches (click = applyBranch, toast + undo) and "版本历史" entries (time · restore).
4. Alternatives: compare strip rows get "+ 可替代" button (adds that type to the selected item's Alternative via addAlternative); module rows show "⇄n" badge when alt_id is set (n = options) → opens strip tab 可替代 listing the options with 切换. Fit header: branch dropdown (+ "*" when diverged) + "保存为分支" (InlineEdit name → captureBranch).
5. Import/export tab: current fit → .exfa.json / EFT / DNA / ESI / XML / multibuy (formats via engine); library → .zip (use `fflate`) laid out by format `toFiles`; "导出到文件夹" / "从文件夹导入" with `showDirectoryPicker` (buttons hidden when unsupported); imports of .exfa.json / .zip / folder / legacy backup JSON go through `migrate`/`fromFiles`; merge rule: id exists → keep the one with newer `modified`; toast summary "导入 X，更新 Y，跳过 Z".
6. Remove legacy-only code paths once migrated (keep the legacy backup import via migrate).
